# Employee Management System

A simple and responsive Employee Management System web application built using HTML, CSS, and JavaScript.

## 🌐 Live Demo

https://anujsingh201.github.io/employee-management-system/

## ✨ Features

- Add new employees
- View employee records
- Edit employee information
- Delete employee records
- Search employees
- Responsive user interface
- Clean and simple dashboard

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

## 📂 Project Structure

employee-management-system/
│
├── index.html
├── style.css
├── script.js
└── README.md

## 🚀 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Anujsingh201/employee-management-system.git
```

2. Open the project folder.

3. Open `index.html` in your browser.
