# Employee Management System

A beginner-friendly Employee Management System built with HTML, CSS, and JavaScript.

## Features

- Add employees
- Search employees
- Delete employees
- Employee count dashboard
- Department count
- LocalStorage data persistence
- Responsive design

## Technologies

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## How to Run

1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Add and manage employees.
